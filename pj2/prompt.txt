## Protocol design (implement exactly this)
1. Resolve the target with `getaddrinfo` (IPv4 only). Determine the local source IP by `connect()`-ing a throwaway UDP socket to the target and reading `getsockname()`.
2. Sending socket: `socket(AF_INET, SOCK_RAW, IPPROTO_RAW)` with `IP_HDRINCL`. Receiving socket: `socket(AF_INET, SOCK_RAW, IPPROTO_ICMP)`.
3. For each TTL from first_ttl to max_ttl, send nqueries probes. Each probe is a hand-built 60-byte datagram: IPv4 header (version, IHL, total length, id, flags/frag, TTL = current hop, protocol = UDP, your checksum, src/dst) + UDP header (fixed source port for the run; destination port starting at 33434 and incrementing by 1 per probe, same scheme as Linux traceroute; length; checksum over the pseudo-header) + zero padding.
4. Record send time with `clock_gettime(CLOCK_MONOTONIC)`. Wait up to waittime seconds with `select`/`poll` on the ICMP socket. For every ICMP packet received: skip the outer IP header (IHL), read type/code, then parse the quoted inner IP header and the first 8 bytes of the inner UDP header. Accept the reply ONLY if inner protocol == UDP, inner src port == our source port, and inner dst port == the outstanding probe's destination port. Ignore everything else and keep waiting until the deadline.
5. ICMP type 11 code 0 (Time Exceeded) → sender is hop N: print address and RTT. ICMP type 3 code 3 (Port Unreachable) → destination reached: print, finish this hop's probes, then exit. Any other type 3 code → print address, RTT, and ` !<code>`, then exit. No reply by the deadline → print `*`.
6. Sleep sendwait milliseconds between probes.
7. Output MUST mirror the sample: hop number right-aligned in 2 columns; first reply in a hop prints `hostname (ip)` via `getnameinfo`, falling back to `ip (ip)`; a later probe in the same hop from a different address prints its own `hostname (ip)` inline before its RTT (hop 2 above); RTT as `%.3f ms`; timeout as `*`.

## CLI (getopt; same letters as Linux traceroute so logs compare 1:1)
      usage: traceroute [-n] [-f first_ttl] [-m max_ttl] [-q nqueries] [-w waittime_s] [-z sendwait_ms] host
- `-f` initial TTL, default 1
- `-m` max hops, default 64
- `-q` probes per hop, default 3
- `-w` timeout per probe in seconds, default 3
- `-z` pause between probes in milliseconds, default 100
- `-n` do not resolve hostnames
Reject invalid or out-of-range values with a usage message and non-zero exit. Exit with a clear message if not running as root.
